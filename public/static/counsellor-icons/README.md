# Counsellor icons

36 animal motifs for counsellor avatars, exported from the ORISO icon master file
(Figma, "001_counsellor_icons", component property `Property 1`). File names are the
Figma property value in lower case, with spaces replaced by hyphens.

Each file is a 48×48 black circle with a white glyph. The app recolours them to the
tenant's primary / on-primary pair (ORISO-UserService#1046, ORISO-Frontend#1540), so the
colours in the files are placeholders.
